To use an interface-compatible modified version of pystray:
1. Exit the Toolkit from its tray menu. Keep a backup of the library folder.
2. Replace _internal/pystray with the modified pystray package directory.
   Keep the package name and the Windows backend/API compatible with 0.19.5.
   This build uses CPython 3.12, Pillow and six. No recompilation of the
   original Toolkit application is required. An installed Program Files
   copy may require Windows administrator permission to edit its files.
3. Remove obsolete library __pycache__ files, if any, and launch the Toolkit.
   Restore the library backup to return to the official release.
   A later Toolkit installer can replace these library files again.
