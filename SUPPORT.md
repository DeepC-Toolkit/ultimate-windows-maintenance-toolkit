# Help and feedback

- Download/install problem or bug: [open a report](https://github.com/DeepC-Toolkit/ultimate-windows-maintenance-toolkit/issues/new/choose).
- Suggest a feature: choose **Feature request** on the same page.
- In the app: **About → Feedback / report a problem → Preview draft → Open GitHub issue**. Review, sign in and submit in your browser. Long drafts may use a clipboard handoff.
- Follow replies through the issue's **Subscribe** button or GitHub notifications. There is no Toolkit private-message inbox.

Include Toolkit version, Windows version, what you expected, what happened and steps to repeat it. Attach a cropped screenshot only when useful. Never post passwords, tokens, personal paths or unreviewed reports/logs.

## Updating an older installation

An update notice does not install the new version. Download the latest offered Setup, exit Toolkit from its tray icon, then run Setup. Your installed version changes after installation. If an old update popup hides its buttons, use [Releases](https://github.com/DeepC-Toolkit/ultimate-windows-maintenance-toolkit/releases) in a browser.

## Setup Type Mismatch

The postinstall date formatting issue from older installers is corrected in 3.4.1 and retained in 3.5.0. Download the new Setup instead of reusing an old file. Report the exact version and error if it still occurs. Isolated fresh/reinstall testing does not cover every Windows configuration.

## Trust warning

The current Setup is unsigned. Windows can show a reputation/unknown-publisher warning. Use only the official release page and check its checksum if needed. Do not disable Windows security protections to use this app.
