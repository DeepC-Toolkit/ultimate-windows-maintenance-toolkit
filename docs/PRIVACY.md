# Privacy

Toolkit keeps preferences, reports and Digital Wellbeing history on this Windows account, under Local AppData. Reports may contain device, account, disk and network details. Review files before sharing them.

Digital Wellbeing records executable names and estimated foreground-use durations. It does not record text typed, screenshots, window titles or URLs. It can be disabled. Toolkit-observed network traffic is separate and is not a billing meter.

Update checks contact api.github.com, and downloads use GitHub's HTTPS asset hosts. No reports, app list or usage history are sent with those checks. GitHub receives ordinary request metadata. Automatic checks can be switched off in Toolkit updates.

Explicit network diagnostics can contact api.ipify.org and the selected network destinations. Windows Update uses the services configured on Windows. Opening a release or feedback link opens the browser.

Feedback is reviewed before opening a GitHub issue. Toolkit does not submit it or attach reports automatically. Issues/replies are public and governed by GitHub's terms. This app has no separate private-message service.
